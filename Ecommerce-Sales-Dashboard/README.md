
# E-Commerce Sales Dashboard

## Project Overview
A Tableau dashboard project analyzing e-commerce sales performance and profitability.

## Dashboard Charts
1. Monthly Sales Trend
2. Sales by Product Category
3. Profit by Region
4. Top 10 Products by Sales

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Units Sold
- Profit Margin
